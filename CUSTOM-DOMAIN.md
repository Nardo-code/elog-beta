# Custom domain preparation

eLOG is ready to use a custom domain, but a `CNAME` file must not be added until the owner has purchased and selected the exact domain. A placeholder would break the working GitHub Pages address.

Current site: https://nardo-code.github.io/elog-beta/

After a domain is owned:

1. Verify the domain in the GitHub account's Pages settings.
2. Add the exact domain under **Repository Settings → Pages → Custom domain**.
3. Configure the domain provider's DNS records using GitHub's displayed values.
4. Keep **Enforce HTTPS** enabled.
5. Verify both the preferred domain and its `www` redirect before sharing it.

No API keys, passwords, DNS credentials, or payment information belong in this public repository.
