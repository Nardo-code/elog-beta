# eLOG security policy

## Beta boundary

eLOG Beta is a local-first static application. Journal entries, screenshots, settings, and backups stay in the tester's browser storage unless the tester explicitly downloads or shares them.

The local password is an interface lock. It does not encrypt browser storage and must not be presented as production account security.

## Reporting a vulnerability

Do not open a public GitHub issue for a vulnerability that could expose user information. Use GitHub's private vulnerability reporting feature on this repository when it is available, or contact the repository owner privately through their verified GitHub profile.

Never include real trades, exported workspaces, screenshots, passwords, API keys, or personal information in a report.

## Supported version

Only the latest public beta at https://nardo-code.github.io/elog-beta/ is supported.
