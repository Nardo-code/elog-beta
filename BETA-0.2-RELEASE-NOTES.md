# eLOG Beta 0.2.0

## Highlights

- Installable Progressive Web App for Windows, Android, iPhone, iPad, and tablets
- Offline app shell after the first successful online load
- Real rule-adherence coaching calculated from each trade checklist
- Per-rule followed/broken counts and outcome differences
- Journal-based coaching calls with an explicit no-trade-signal boundary
- GitHub-based beta feedback with a privacy review before public submission
- Structured feedback and bug-report forms
- Automated static checks and CodeQL security scanning
- Custom-domain preparation without breaking the current Pages URL

## Privacy boundary

Journal data remains stored on each device. Installation does not create an account or cloud sync. Feedback is posted publicly only after the tester reviews and submits the GitHub issue.

## Known limitations

- Testers need a GitHub account to submit GitHub issues.
- A chosen and purchased domain is required before custom-domain activation.
- iPhone and iPad installation uses Safari's **Share → Add to Home Screen** flow.
- Rule coaching describes correlations in saved journal data and is not financial advice or a trade signal.
